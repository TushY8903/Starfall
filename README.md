# 🚀 Starfall

Starfall is a neon-themed 2D space shooter game developed as an individual Software Development Project using Electron, HTML, CSS, and JavaScript.

## 🎮 Current Features

- Electron desktop application
- Neon arcade visual style
- Player spaceship
- WASD and arrow key movement
- Player movement boundaries
- Animated neon stars
- Shooting mechanics
- Enemy spaceships and spawning
- Bullet-enemy collision detection
- Player-enemy collision detection
- Player health system
- Score system
- Game Over screen and detection
- Pause and Resume functionality
- Pause menu with Resume, Restart, and Main Menu options
- Restart functionality
- Main menu and Controls screen

## 🕹️ Controls

| Key | Action |
|---|---|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |
| Space | Shoot |
