# 🚀 Starfall

**Starfall** is a neon-themed 2D space shooter game developed as an individual Software Development Project using Electron, HTML, CSS, and JavaScript.

## 🎮 Features

- Electron desktop application
- Neon arcade visual style
- Player spaceship
- WASD and arrow key movement
- Player movement boundaries
- Animated neon stars
- Shooting mechanics with sound effects
- Enemy spaceships and automatic spawning
- Bullet-enemy collision detection
- Player-enemy collision detection
- Player health system
- Score system
- Main menu and Controls screen
- Pause and Resume functionality
- Pause menu with Resume, Restart, and Main Menu options
- Game Over screen with final score
- Restart functionality
- Custom application icon

## 🕹️ Controls

| Key | Action |
|---|---|
| W / ↑ | Move Up |
| S / ↓ | Move Down |
| A / ← | Move Left |
| D / → | Move Right |
| Space | Shoot |

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Electron
- HTML Canvas

## 💻 Run from Source Code

1. Clone or download this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the game:

   ```bash
   npm start
   ```

## 📦 Windows Installation

Download the Windows installer from:

[Download Starfall v1.0.0](https://github.com/TushY8903/Starfall/releases/tag/v1.0.0)

Run `Starfall.Setup.1.0.0.exe` to install the game.
